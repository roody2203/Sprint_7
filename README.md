# Sprint_7

This project was completed as part of the 7th Yandex Practicum sprint.
The project includes automated API tests in Java using JUnit4 and Allure.

### Run the project

- Go to the project folder
- Launch the project
```
mvn clean test
```

### Allure report

Allure report is located in 
```
target/allure-results/.
```
